# Revo3 Demo 集合

双击 `index.html` 即可在浏览器中打开。也可运行 `python3 serve.py`，访问终端显示的本地地址。

- 原来的六个分类文件夹及视频保持不变。
- `catalog.js` 保存全部 34 段视频的中英文标题、caption 与分类。
- `assets/videos/` 是适合浏览器播放的 H.264 MP4 副本，保留原画面、视频时长和比例，钢琴演奏类保留原有音轨，其余类别全部移除了音轨。钢琴类共 9 段，其中 8 段有音轨，双手按键训练短片的原文件本身无音轨。
- `assets/posters/` 保存从视频提取的预览帧。
- 中英切换会同时更新分类、标题、caption 和操作文字，并记住本机语言偏好。
- 点击封面放大播放；默认按当前分类顺序自动连播，并在最后一段后循环。支持上一段、下一段、关闭自动连播及全屏展示；浏览器支持时会在展示期间保持屏幕常亮。

说明根据素材中的可见动作与文字编写。网站分为 7 类，钢琴演奏单独分类（不移动原素材）；caption 标明运动学轨迹优化与仿真性质。抛接球视频标注为训练过程，包含掉球与重置，不将其描述为成熟技能。

公开网站：https://davidlxu.github.io/Revo3-Demos/

GitHub Pages 从 `main` 分支根目录发布。更新网页或 `assets/` 后提交并推送即可部署。仓库只收录网站及处理后的媒体；原始素材与本地构建缓存通过 `.gitignore` 排除。

网站媒体经过 H.264 压缩；钢琴演奏采用最高 960px 宽、24 fps、AAC 96 kbps，其余类别保持最高 1280px 宽并移除音轨。原始素材与压缩前备份仅保存在本地。

演示可同时属于多个分类：带触觉观测的掌内转球同时列入触觉与强化学习，全部演示只计一次。

伟钛多通道触觉可视化保留 1920px 宽，以呈现多窗口曲线与触觉细节。

自动连播会在当前视频已有足够播放缓冲后预载下一段，并在换片时复用该播放器。每次最多预载一段；关闭连播或播放器会取消预载。实际预载量由浏览器决定。
